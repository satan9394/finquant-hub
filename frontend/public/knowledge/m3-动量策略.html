策略 03 · 趋势跟踪

动量策略

"强者恒强，弱者恒弱"——资产价格的趋势一旦形成，往往会延续一段时间。顺势而为，不做逆势判断。
🚗 生活类比： 想象你在高速公路上开车。一辆大卡车一旦加速到 100km/h，不会立刻停下来——它有巨大的"动量"。 股票也一样，当它开始持续上涨，会吸引更多买家入场，推动价格继续走高。 动量策略就是在卡车刚加速时跳上车，在减速前跳下来。

💡 策略思想

趋势自相关——过去一段时间涨得好的资产，接下来一段往往继续涨。动量策略通过测量价格变化率（N日收益率或 RSI 等指标），买入强势资产、卖出/避开弱势资产。

⚙️ 实现方式

计算过去 N 天的收益率作为动量信号（如过去 12 个月的收益率）。动量大于 0 且超过阈值时买入，动量转负时卖出。也可以做多动量最强的几只股票，同时做空最弱的几只。

📋 执行步骤

  1. 选定资产池，确定动量计算周期（如 60 天收益率）
  2. 每天计算各资产的动量值 = (今天价格 - N天前价格) / N天前价格
  3. 动量超过阈值（如 +5%）→ 买入；动量跌破 0 → 卖出
  4. 也可以构建多空组合：做多动量最强的前 20%，做空最弱的后 20%
  5. 动量策略在市场趋势明显时效果极佳，剧烈反转时容易回撤
