# 任务模板 — 配 PROJECT_CONTEXT.md 使用

## 用法

```
1. 截屏 → 保存到 task/ 目录（png）
2. 打开 Claude Code 会话（当前会话）
3. 说：
   "处理 task 目录下的任务 [文件名]"
   或者拖截图到终端里
4. 我会读取截图，调出相关代码上下文，直接执行
```

## 任务描述示例

```
处理 task 目录下的任务 截屏2026-07-28.png

截图是投资组合页面，看到以下问题：
1. 港股持仓的 PnL 显示为 0
2. 页面一直显示"加载中..."卡住
3. 表格列宽太窄，数字显示不全
```

这样我在当前会话直接读代码 → 修 bug → 验证，不需要你离开会话去 ChatGPT。

## 如果坚持用 ChatGPT 的工作流

```
你是一个全栈工程师。请在以下项目上下文中执行我的开发需求。

=== 项目上下文 ===
[粘贴 task/PROJECT_CONTEXT.md 的全部内容]

=== 截图描述 ===
[描述你看到的页面和问题]

=== 需求 ===
[具体要做什么改动]

请给出：
1. 需要改动的文件路径
2. 具体代码修改
3. 如何验证
```
