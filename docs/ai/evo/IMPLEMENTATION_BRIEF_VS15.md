# IMPLEMENTATION_BRIEF — Vertical Slice 15：用户可见文本与实现对齐（检测到的 Python 版本 + 备份保留措辞）

> Orchestrator 第五阶段产物，2026-09-11（机器实际日期）。来源：**A2 的 P1-1 后半**（"Python 版本不符时说明检测到的版本"）+ **VS-9 评估者的非阻断②**（`QUICKSTART` "保留 7 份"与实现不符）。两项**高度同源**——都是"用户见到的文字与实际行为不一致"，故合并为一卡。

## 目标
用户见到的话必须**反映实际发生的事**：①Python 版本不符时**告诉他检测到的是哪个版本**（而不是让他怀疑"我明明装了"）；②备份**不会自动删除**这件事必须写准。

## 当前问题（均已核实）
**A. `start.bat:157-158` 的 Python 失败提示不说明检测到的版本**
- 本机实况（编排者实测）：`where py` 失败（**无 py 启动器**）→ 走 `:python_path`（`:45`）→ `:46` 检查 `python` 是否为 3.12 → **实际是 3.13.5** → `goto venv_failed`（`:47`）。
- 而 `:158` 只说"通常是没有装 Python 3.12 或安装时没勾选加入 PATH" ⇒ 一个**装了 Python 3.13** 的用户会看到这句话并认为自己明明装了，**不知道问题出在版本号上**。
- 附：`python -V` 经实测输出到 **stdout**（故 `2>nul` 不会吞掉版本号）。

**B. `docs/QUICKSTART.md:169` 自相矛盾**
- 同一句先写"**滚动保留最近 7 份**"（暗示自动裁剪），紧接着又写"看到「[提示] 备份超过 7 份」时，请把多余备份文件…移走或删除"——**后者恰恰证明不会自动删除**。
- 实现事实：`start.bat` 的备份段**只提示不删**（`:117` 内 `if($files.Count -gt 7){ Write-Host '[提示] 备份已超过 7 份…' }`；`:113` 注释亦自认"超过时只提示不自动删除（遵守'删除一律进回收站'铁律，由用户处理）"）。

## 理想行为
1. `:venv_failed` 先说明**需要什么**，再**打印检测到的版本**；若 PATH 中根本没有 `python`，明确说明这一点（也是可诊断信息）。
2. 其余处置步骤（安装指引、PATH 勾选、进阶命令）**保持不变**。
3. `QUICKSTART:169` 把"滚动保留最近 7 份"改为**准确表述**：超过 7 份时**只提示、不自动删除**，由用户自行清理（并保留"回收站/按习惯处理"的既有指引）。

## 涉及模块
- `start.bat`（仅 `:venv_failed` 段）
- `docs/QUICKSTART.md`（仅备份那一段）

## 不能破坏
- **任何退出码与流程不得变化**：`:venv_failed` 末尾仍 `goto fail`；不改 `:python_path`/`:41`/`:46` 的判定逻辑（本卡**只改提示文本**）。
- 不改备份实现（`:117` 的 PowerShell）——**文本向实现对齐，不是实现向文本对齐**。
- 不改 `:pip_failed`/`:build_failed`/`:bun_missing` 的既有文案。
- `start.bat` 保持 **CRLF**（LF-only = 0）与有效 UTF-8；不加依赖；不删文件（删除一律回收站）；不 commit。

## 验收标准（可判定）
1. `:venv_failed` 输出中**出现检测到的版本**：在 `python` 为 3.13 的环境下运行该段，输出含 `Python 3.13` 字样；在 `PATH` 无 `python` 的环境下运行，输出**不出现**版本号但**出现**"PATH 中没有 python"一类说明。
2. `:venv_failed` 的**其余行逐字未改**，末尾仍 `goto fail`；`:41`/`:46`/`:47` 与 `:python_path` 逻辑未改（可用 `git diff` 证明改动只落在提示文本行）。
3. `QUICKSTART:169` 不再出现"滚动保留最近 7 份"这一表述；**明确写出"只提示、不自动删除"**；且与 `start.bat:113/:117` 的实现一致。
4. 字节级：`start.bat` CRLF 完整（LF-only = 0）、严格 UTF-8、`git diff --check` 干净。

## 错误场景
- `python` 不在 PATH：`call python -V 2>nul` 无输出（cmd "不是内部或外部命令"走 stderr 被抑制）⇒ 随后那行说明必须出现，不得让用户看到空白无解。
- `python -V` 因其他原因失败：同上，不得因此改变退出码或中断。
- 版本号形如 `3.13.5`：不得截断或格式化成错误内容。
