# PROD-045: 组合风险到预警和定期复盘闭环

> 状态：`[DONE]`  
> 阶段：Productization Phase 4

## 用户问题

组合风险体检已经能指出主要风险并比较假设，但结果仍停留在当前页面。用户不能把具体风险证据带到预警创建，也没有一个可恢复的复盘待办来记录“何时重新检查、检查什么”。

## 目标行为

风险结果完成后，用户可以显式选择“去预警中心”，仅把组合名称、关注资产、指标、当前值、来源截止时间和建议条件预填到路由状态；Alerts 页面必须要求用户确认并保存。用户也可以显式创建本地复盘待办，记录风险摘要、创建时间和建议复查时间，可完成、删除并撤销删除。

## 明确非目标

- 不自动调用预警创建接口，不自动启用规则，不发送通知或外部消息。
- 不创建订单、不采用优化器权重、不修改真实持仓。
- 不把历史 VaR/ES、回撤或集中度解释为未来触发概率。
- 不新增后端表或依赖，不修改架构或 `reference/`，不提交或发布。

## 验收

- 只有成功风险结果后才显示预警预填与复盘动作；导航本身不调用写接口。
- Alerts 明确展示预填来源和原始风险证据，用户编辑并点击保存前不创建规则。
- 本地复盘待办只保存派生摘要和时间，不保存行情曲线或伪造新数值；删除可撤销。
- 页面刷新后待办可恢复，预警仍需显式保存；桌面/窄屏可操作。
- 前端聚焦/完整测试、构建和浏览器闭环验证通过。

## 回滚方式

移除风险结果动作、Alerts 预填读取和本地待办模块；现有风险工作台与 Alerts CRUD 不受影响。
