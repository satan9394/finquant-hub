- 后端 schema / 认证 / 用户隔离

## 完成标准

- `/analysis/:ticker` 页头为 Entity 卡片（名称、代码、市场、实时价、涨跌、Watch/Monitor/Compare 动作）+ 8 tab：Overview/Thesis/Financials/Valuation/Peers/Earnings/Price/Research。
- Agent 模式选择器（Fast/Analyst/Deep Research/Review）在 Research 上下文内切换，无独立路由跳转。
- Deep Research 运行时展示 Research Plan（步骤 ✓/●/○）+ Progress + Sources + Activity，可 Pause / Change scope。
- Thesis 块为结构化对象：stance（Bullish/Neutral/Bearish）、conviction、core thesis 列表、Evidence For/Against（带 source refs）、Catalysts、Invalidation Rules；Agent 更新 Thesis 时显示 Thesis Drift / Conviction Change / New Supporting / New Contradicting Evidence。
- Evidence 系统：重要数字带 `[n]` 引用，点击展开 Evidence Rail（source_type/authority/publisher/published_at/page/excerpt/url/confidence），提供 `[Open document]` `[Add to thesis]`。
- Multi-Agent Review 输出 Consensus / Disagreement / Unresolved Questions / Evidence conflict，不再呈现"聊天室"式表演。
- Compare 支持自然语言输入（如"贵州茅台 vs 五粮液"）自动创建对比网格，每行可 `Ask Agent about this row`。
- 全部新组件文案走 `t(key)`，zh/en 双语可用。
- `bun run build` 通过；前端测试全过；内置浏览器截图（Entity/Research/Deep Research/Review/Compare，1440 + 390，zh + en）存 `docs/ui-current/`。
