## 一句话

`docs/ai/BACKLOG-NNN.md`（**顶层**）与 `docs/ai/tasks/BACKLOG-NNN.md`（**本目录**）是**两个不同用途的文件族**；
**同名 ≠ 同内容**。看到 `BACKLOG-NNN.md` 时，**必须先确立完整路径**，再判断它是"任务卡"还是"完成证据"。

| 路径 | 用途 | 典型首行 |
|---|---|---|
| `docs/ai/BACKLOG-NNN.md` | **任务卡**（执行契约：目标 / 允许修改 / 禁止修改 / 完成标准 / 门禁） | `# BACKLOG-NNN: <标题>` |
