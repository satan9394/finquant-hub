# PROD-053: P2 因子、风险贡献和压力测试能力证据审计

> 状态：`[DONE]`  
> 阶段：Productization Phase 5

## 用户问题

Alpha 页面已明确展示 IC、完整分位和衰减分析的数据边界，组合页面也明确缺少完整相关矩阵、逐资产风险贡献和压力测试合同。如果直接根据现有汇总值补图或补数，会把设计状态伪装成可验证的专业能力。

## 目标行为

逐项追踪 Alpha 因子、组合风险贡献和压力测试从输入、计算、持久化到页面展示的真实合同，判断每项是当前可用、数据不足还是仅设计。只对现有真实数据能独立支持、口径可解释且可测试的最小能力实施接线；其余在产品中继续明确所缺输入和方法边界，不生成合成或推断数值。

## 范围内文件

- `frontend/src/pages/AlphaResearch.tsx`、`frontend/src/pages/Portfolio.tsx` 及其直接测试
- Alpha/组合相关前端服务、类型和后端模拟/组合回测合同，仅在真实证据支持最小实现时修改
- `docs/ai/PRODUCT_CAPABILITY_MATRIX.md`

## 明确非目标

- 不用组合权重、平均相关性或已有汇总风险值反推出逐资产风险贡献或完整相关矩阵。
- 不用收益缩放、固定跌幅或模型生成数据伪装历史/情景压力测试。
- 不把短样本时间序列相关性命名为横截面 IC，不用不稳定分组补完整分位或衰减曲线。
- 不新增数据源、依赖、后端表或许可受限数据，不修改架构或 `reference/`。
- 不提交、发布、发送、远端 Alpha 提交、下单或修改真实持仓。

## 验收

- 每项能力都有可追踪的输入、样本、期间、来源、算法和输出证据，并明确标为可用、数据不足或设计状态。
- 任何新增数值必须来自现有真实数据合同、能够独立复算并有确定性测试；没有足够证据时保持非数值说明。
- 页面不把权重、平均相关性、短样本相关或假设冲击误称为风险贡献、IC、衰减或压力结果。
- 聚焦测试、相关完整回归、构建及桌面/窄屏浏览器边界验证通过；若涉及后端，相关 pytest 与 Ruff 通过。

## 回滚方式

移除本任务新增的最小接线或证据说明；保留原 Alpha 本地模拟、组合风险工作台及其已有真实数据合同。
