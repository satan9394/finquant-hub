# UI-004 - 视觉 Token 收敛与反 slop 审计

## 状态

`[BLOCKED]`

## 优先级

P2

## 用户结果

全站视觉由 `--fq-*` design tokens 统一驱动，消除"大圆角 + 大卡片 + 大空白 + SaaS Admin Dashboard"感，转向"低装饰、较高信息密度、稳定空间位置"的金融研究终端。行情颜色与系统状态颜色严格分离（中国市场红涨绿跌），关键组件（表格/图表/时间线/证据/事件流）成为第一等组件，并完成反 AI-slop 全站审计。

## 前置

- `UI-000` ~ `UI-003` 已完成（页面结构、i18n、组件体系就绪）
- 前端构建与测试基线全绿

## 允许修改

- `frontend/src/app.css`（tokens 收敛：radius 8-16→6-8px、shadow 弱化、spacing 4px 网格）
- `frontend/src/styles/*`（如有独立设计系统文件）
- 各页面/组件的 `.tsx` 中硬编码色值 → `--fq-*` 变量
- `frontend/src/i18n/zh.ts`、`en.ts`（如需补充文案）
- `frontend/tests/*`（视觉相关测试调整）
- `docs/UI_OPTIMIZATION_PLAN.md`、`docs/ui-current/`

## 禁止修改

- 后端代码、schema、认证
- 新增依赖；`reference/`
- 改动组件行为/数据绑定（纯视觉收敛，不改逻辑）
- 删除既有 `--fq-*` token 定义（只增不删）

## 完成标准

- `--fq-*` tokens 全站消费：`grep` 检查 `frontend/src` 无新增硬编码色值残留（排除既有遗留并迁移）。
- 行情/系统状态颜色分离：新增 `--fq-system-info/warning/error` 三组，与 `--fq-price-up/down` 语义隔离；`grep` 验证系统状态不再复用行情色。
- 视觉收敛：radius 收敛到 6-8px、card shadow 尽量去除、间距对齐 4px 网格、字体层级清晰。
- 反 slop 审计清单（来自 taste-skill）全过：
  - [x] `h-screen` → `min-h-[100dvh]`
  - [x] 无 flex 百分比数学布局（用 CSS Grid）
  - [x] 无纯黑 `#000000`
  - [x] 无 AI 紫渐变默认美学
  - [x] 无三列等宽卡片堆砌
  - [x] Loading/Empty/Error 三态齐全
  - [x] 无 `window.addEventListener('scroll')` 动画
  - [ ] 按钮/表单 WCAG AA 对比度
  - [x] 颜色/形状一致性锁（单一 accent + 单一 radius 体系）
- 13 个第一等组件落地并在对应页面使用：MetricStrip / FinancialTable / TimeseriesChart / CompareGrid / EventTimeline / EvidenceCard / ThesisBlock / MonitorCard / AgentRun / SourceChip / StatusChip / ActionBar / CommandComposer。
- 全站文案走 `t(key)`，zh/en 双语（承接前序 Phase）。
- `bun run build` 通过；前端测试全过；内置浏览器截图（全 8 导航，1440 + 390，light + dark，zh + en）存 `docs/ui-current/`，对比前序截图确认视觉无回归。

## 验证声明

反 slop 审计为静态规则检查 + 截图人工复核；WCAG 对比度按既有审计方法（如 PROD-061 的 contrast 测量）复测，不引入新工具。radius/shadow 收敛可能影响少量既有测试的像素断言，允许调整测试以匹配新视觉基线，但不得放宽行为正确性断言。
