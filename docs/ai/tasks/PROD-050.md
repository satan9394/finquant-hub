# PROD-050: 保存常用指标、布局密度和研究模板

> 状态：`[DONE]`  
> 阶段：Productization Phase 5

## 用户问题

专业用户会反复查看同一组指标、使用相似研究模板，并需要更紧凑的信息密度；当前这些偏好分散在页面状态或一次性输入中，刷新后难以恢复。直接扩大 Settings 或改变默认布局又会让新手体验重新变复杂。

## 目标行为

先盘点现有设置、指标选择、模板和本地持久化能力，复用最小合同让用户显式保存常用指标、布局密度和研究模板。专业偏好可恢复、可重置，并且只改变展示与启动配置，不改变数据源、指标算法、期间或金融口径；新用户仍看到当前简洁默认值。

## 范围内文件

- 现有 Settings、ResearchWorkspace、StockAnalysis、StrategyLab 或 AlphaResearch 中与偏好直接相关的最小页面/组件
- `frontend/src/features/` 下确有必要的最小偏好模块
- 对应前端测试
- `docs/ai/PRODUCT_CAPABILITY_MATRIX.md`
- `docs/ai/EXEC_PLAN.md` 和本任务卡

## 明确非目标

- 不重构全局状态管理，不新增后端表、依赖、账户同步或跨设备同步。
- 不保存原始行情、用户未显式保存的观察输入、凭据或模型秘密。
- 不改变指标算法、数据源优先级、复权、期间、成本、基准或任何金融口径。
- 不一次覆盖所有页面，不修改架构或 `reference/`，不提交或发布。

## 验收

- 先证明并复用现有偏好/模板能力；没有现成能力时才增加最小本地合同。
- 用户必须显式保存；刷新后恢复，重置后回到当前新手默认值。
- 保存内容有版本和输入校验，损坏或旧数据安全回退，不静默改变数据口径。
- 桌面与窄屏都可操作，专业密度不破坏默认层级或无障碍标签。
- 聚焦/完整前端测试、构建和浏览器恢复/重置验证通过。

## 回滚方式

移除专业偏好入口和最小本地持久化模块；各页面现有默认指标、模板和布局保持不变。

## 完成记录

- 新增版本化 `finquant_professional_preferences_v1` 本地合同，只保存常用指标键、布局密度和真实 Alpha 目录模板 ID；旧版本、损坏 JSON、未知指标/密度和非法模板 ID 都安全回退。
- Settings 提供显式保存与恢复默认；新用户仍为全部 MA/MACD/KDJ/RSI、舒适密度、无常用模板，App 仅通过 Ant Design `componentSize` 改变展示密度。
- Stock Analysis 只按偏好隐藏/展示既有指标说明与子图，方法区披露当前展示指标；不改变行情请求、指标算法或任何金融口径。
- Alpha 页面只能从实时返回的 5 个真实目录模板中显式保存常用模板；刷新恢复模板但观察输入保持为空，不自动模拟或远端提交。
