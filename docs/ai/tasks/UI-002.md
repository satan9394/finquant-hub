## 完成标准

- Monitor 为一级导航入口（承接 `/alerts`，可重定向或改菜单 key）。
- 支持 10 种 Monitor 类型 Chip 筛选：Price / Technical / Fundamental / Estimate / News / Filing / Thesis / IPO / Supply Chain / Agent Research。
- MonitorCard 展示：名称、优先级徽标、State、Last check、Next check、Sources、Changes、最新一条 New 事件、`[Inspect] [Run now] [Edit]`。
- IPO / 产业链持续监控为"一等公民"（可建 `长鑫科技 IPO Watch` 这类 Card），不混同为价格预警。
- Today 首页自上而下：处理队列（需要处理/Agent 运行中/新重大变化/今日事件）→ My Universe（Portfolio/Watchlist/IPO Watch/Themes）→ 市场脉搏（指数/利率/汇率/商品/行业）→ Research Runs（状态进度条）。
- 系统自身状态（AVAILABLE/UNCONFIGURED/UNKNOWN）不再出现在 Today 首屏主体区，收敛到右上角状态入口。
- 全部文案走 `t(key)`，zh/en 双语。
- `bun run build` 通过；前端测试全过；内置浏览器截图（Today + Monitor，1440 + 390，light + dark，zh + en）存 `docs/ui-current/`。
