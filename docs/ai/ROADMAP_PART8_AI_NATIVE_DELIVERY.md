## 8.1 V1 — 3 个月目标（AI 原生 OS 最小可用版）

**一句话**：把"功能集合"收敛成"一个入口 + 三个中心"，先修 P0 断链，让非技术用户 10 分钟内完成第一次研究闭环。

### 删除什么（Remove）

混乱源头按"造成困惑 vs 提供价值"逐一裁决，全部进回收站流程，不做永久物理删除：

1. **合并四个 AI 页面**：`chat`、`discussion`、`research`、`swarm` 页面收编为**统一 AI 研究中心**。这四处散落的 AI 能力正是"UX P2 — AI scattered across 4 pages"的根源，也是用户无法判断该进哪个页面的困惑点。内部流水线不动，只合并入口与路由。
2. **首页信息过载**：裁掉系统状态卡片（进程/DB/链接监控）、技术性预警横幅（这些属于运维信号，不属于投资用户）。首页只保留：AI 命令栏 + 今日决策收件箱 + 三类入口卡片 + 新手引导。
3. **旧回测表面**：`/api/backtest/runs`（legacy close-only）前端入口下架，只保留 v2 next-open 回测；手写 HTML 表格逐步替换为 AntD 组件。
4. **旧组合表台面化**：`portfolio_groups/portfolio_items`（legacy 表）从前端导航与 API 主路由中禁用，改为只读隐藏，避免与 `portfolios/positions` 并列造成数据不一致感。
5. **导航过度暴露**：6 组导航收敛为"首页 / AI 研究中心 / 投资委员会（占位）/ 组合中心 / 设置"5 项，隐藏内部模块名。
6. **禁用项**：把"研究*工作区堆叠（pileup）*"相关的临时速记入口、未完成的 onboarding 空壳禁用，避免半成品暴露。

原则：删除的是**导航/入口/表面**，不是**能力**。所有被删页面的数据、流水线、API 仍保留在后端。

### 保留什么（Keep）

- **4 条 AI 流水线原样保留**：chat（意图承接）、research（4-agent + team-lead 统一报告）、discussion（多 agent 讨论）、swarm DAG。它们已建成，是 AI 内核。
- **13 个本地工具全部保留**：不重写、不替换，继续作为 function_calling 的工具层。
- **证据纪律**：`FACT/INFERENCE/MODEL_OUTPUT/UNKNOWN` 四级分类原样保留并强化为"证据链表面"。
- **SSE 流式**：6 条管线保留，V1 补齐无障碍（aria-live/键盘焦点/可暂停），修 P0 的"SSE accessibility missing"。
- **Paper Portfolio 账本**、**thesis drift 校验**、**decision inbox**、**memory（投资记忆）**全部保留并接入新中心。
- **能力降级链**：market_data 多源熔断/降级、无 key 启动降级，是本地 OSS 生存能力，保留。

### 新增什么（Add）

1. **统一 AI 命令栏（首页核心）**：单条输入承接"研究茅台 / 挑战我的观点 / 汇报今日 / 回测这个策略"，取代让用户理解内部模块的旧入口。
2. **AI 任务路由**：`意图 → agent → 工具 → 结果 → 下一步建议`的显式管线。意图识别器决定进 chat/research/discussion/swarm 哪条流水线、挂载哪些工具。
3. **加入自选/加入组合按钮（P0 修复）**：在研究结果、论文、报告卡片上补齐"加入自选 + 加入组合"，打通"研究→关注"断链，这是 V1 最重要的单点修复。
4. **新手模式（Level 1）**：默认遮蔽高级项，向导式完成第一次研究→加入自选→保存论文。
5. **证据链表面**：每项结论下方可展开"事实/计算/推断/未知 + 来源 + 时间 + 方法"，兑现 evidence discipline 的可视化承诺。
6. **术语 tooltip 系统**：PE/PB/回撤/IC 等术语悬浮解释（P1"无术语解释"修复）。
7. **新整合页：AI 研究中心**（chat+research+discussion+swarm 统一工作台，带左侧会话树）。
8. **新整合页：投资委员会**（V1 为只读议程/纪要占位，V2 成真）。
9. **新整合页：组合中心**（portfolios/positions 单一权威视图 + paper ledger）。

### 技术工作项

- **后端**：新增 `intent_router` 服务（意图→流水线/工具映射）；新增"加入自选/组合"端点（写 watchlist + portfolio_items→positions 接线）；新增 `evidence_chain` 聚合查询（把 evidence/provenance 关联到报告段落）；新增术语词典端点；`backtest/runs` 入口标记 deprecated。
- **DB schema**：新增 `watchlist` 表（若缺）、`term_glossary` 表、`ai_task` 路由日志表（记意图→agent→工具→结果 lineage）；schema 版本递增（当前 v23），严格走迁移。
- **前端**：新建 `CommandBar`、`EvidenceChain`、`TermTooltip`、`AICenter`、`Committee`、`PortfolioCenter` 组件；`research→fold` 卡片加按钮；导航重构 5 项；SSE reader 补无障碍。
- **重构纪律**：不引入 ORM/DAL（V1 保持原始 SQL），只做路由与表面合并，控制回归面。

### 成功指标

- **研究→关注完成率**：从"研究结果被倒入自选/组合"的比例，目标 ≥ 60%（P0 断链修复的直接度量）。
- **首次价值时间 TTFV**：新手从打开到完成第一次研究并保存，**< 10 分钟**（已有产品指标合同支撑）。
- **新手完成率**：Level 1 新用户完成"研究→加入自选→保存论文"全流程的比例，目标 ≥ 50%。
- **任务路由准确率**：意图→正确流水线/工具的比例 **> 85%**（误路由会让入口承诺崩塌）。
- **SSE 可达性**：无障碍审计通过（键盘可达 + aria-live），缓冲 P0 修复验证。

V1 退出标准：首页只留一个 AI 入口 + 三个中心；研究→关注断链闭环；证据链 + 术语解释已上线；TTFV 达标。

## 8.2 V2 — 6 个月目标（AI 投资委员会 + 投资管家）

**一句话**：从"帮用户研究"升级到"替用户持续跟踪并组织集体验证"——委员会承担决策质量，管家承担主动性。

### 删除什么（Remove）

- **Legacy 回测**：`/api/backtest/runs` 端点正式下线（V1 已停前端入口，V2 删后端），只留 v2 next-open 引擎。
- **旧组合表**：`portfolio_groups/portfolio_items` 完成数据迁移到 `portfolios/positions` 后删除，终结"两套组合表"技术债。
- **手写 HTML 表格**：全部替换为 AntD 表格组件，统一样式与可访问性。

### 保留什么（Keep）

- **V1 全部新增**：统一命令栏、任务路由、AI 研究中心、委员会、组合中心、新手模式、证据链、术语解释。
- **4 条核心 AI 流水线 + 13 工具**：原样保留，作为委员会与管家的执行引擎。
- **证据纪律 / SSE / Paper ledger / decision inbox / memory / thesis drift**：全部保留。

### 新增什么（Add）

1. **完整投资委员会会议流**：`议程 → 发言 → 交锋 → 投票 → 总结 → 下一步` 六步闭环。委员会由研究员 + 多空对抗 + 风险官等 agent 角色组成，产出可在研究→决策中引用。
2. **AI 投资管家（proactive）**：不是被动问答，而是基于 thesis/portfolio 主动巡检，发现敞口变化、证据更新、风险触发时主动推送并建议下一步动作。
3. **研究报告自动刷新**：数据变化触发器 → 关联报告/论文自动重跑并 diff，把"旧报告误导"转化为"变化可追踪"。
4. **多 agent 论文辩论取代单 agent 挑战**：`Challenge My Thesis` 从单 agent 升级为多 agent 交锋（多空 + 替代解释 + 证伪者），提升对抗质量。
5. **组合风险 X 光自动化**：集中度/回撤/VaR/ES/相关性自动生成并进入委员会与管家话语。
6. **论文漂移监控自动化**：从手动触发升级为订阅监控目标，漂移时自动提醒并给出引导的争议点。

### 技术工作项

- **auto thesis-drift cron**：把确定性漂移 + evidence-aware 漂移引擎挂到 scheduler，按 monitor targets 订阅，漂移落 decision inbox + 通知。
- **portfolio risk X-ray pipeline**：风险服务定时计算，结果入委员会议程与管家巡检项。
- **报告更新触发系统**：数据源变化版本化 → 命中订阅 → 重跑流水线 → diff 报告 → 标记变化点。
- **多 agent 辩论引擎**：discussion_orch 扩展为可配置角色板 + 过程纪要 + 投票汇总，复用现有编排器不新建框架。
- **技术债续清**：V2 同时推进"手写 HTML → AntD"替换与旧组合表迁移。

### 成功指标

- **委员会采用率**：月触发委员会会议并产出纪要/下一步的活跃对象占比，目标 ≥ 40%。
- **管家日活**：投资管家 DAU / 活跃用户，目标 ≥ 30%（主动价值而非被动问答）。
- **自动刷新命中率**：触发重跑的报告中"确实发生变化"的比例 ≥ 70%（避免噪音轰炸）。
- **漂移检出提前量**：从证据变化到漂移提醒的平均提前时间 > 阈值（以天计），量化主动监控价值。

V2 退出标准：委员会六步闭环可用；管家能主动提示并推动下一步；旧回测/旧组合表已删除；技术债（手写表格、两套组合表）清零。

## 8.3 V3 — 12 个月目标（专业 Alpha + MCP 生态 OS）

**一句话**：从"AI 原生研究 OS"升级为"带专业量化能力 + 可扩展生态的操作系统"，打通研究→量化的专业价值。

### 删除什么（Remove）

- **技术债专项清算**：ticker 规范化（canonical form）、DAL 提取、幂等 key 补齐、前端单个 `api.ts` 拆分、E2E 测试套件。这些不是删功能，是还架构债，降低后续一切迭代的回归成本。

### 保留什么（Keep）

- **V1 + V2 全部新增**：三中心、命令栏、委员会、管家、自动刷新、辩论引擎、证据链、paper ledger、记忆。
- **全部成熟的 AI 流水线与工具**：4+ 条流水线、13+ 工具原样运营，作为 OS 内核。

### 新增什么（Add）

1. **Alpha 因子 AI 副驾**：`自然语言 → 因子表达式 → 本地模拟 → IC/ICIR 结果`。用户说"低波动 + 高股息组合因子"即可生成受限因子表达式并回测 IC，兑现 WQ alpha 研究能力。
2. **MCP 生态**：第三方工具市场 + 社区贡献工具，让 OS 可扩展，不再是自产自销的封闭工具集。
3. **研究记忆知识图谱**：实体/关系/证据链接，把零散记忆升级为可探索的关联网络（复用既有 memory + evidence 合同，仍是可重建读模型）。
4. **模型无关路由**：多 LLM 供应商抽象 + 自动切换（成本/质量/可用性路由），摆脱单供应商锁定，符合 adapter-ready。
5. **Pro 模式解锁**：全量 alpha 因子、完整回测套件、swarm 团队、MCP 工具面向专业用户开放。

### 技术工作项

- **技术债**：ticker 规范化（canonical form + provider 映射收敛）；DAL 提取（纯逻辑服务保持零 IO，DAL 层收拢原始 SQL，仍不引 ORM）；幂等 key 全写路径补齐；前端 `api.ts` 按域拆分；E2E（Cypress/Playwright）核心旅程。
- **MCP 市场协议**：定义工具 manifest/版本/权限/沙箱，市场订阅与本地安装。
- **知识图谱 DB schema**：实体表 + 关系表 + evidence 链接表，作为可重建读模型。
- **多 LLM 抽象**：Provider 接口 + 路由/降级/成本表，接入现有 llm_client。

### 成功指标 + 北极星指标

**北极星指标**：**"每周产生可执行投资决策的活跃研究会话数"** —— 不是会话数，而是落在"可执行决策"上的会话数。它同时约束量的增长与质的落地：会话再多，若没有可执行的下一步就等于零。V1/V2 的所有入口与主动机制都服务于把它推高。

**V3 指标**：
- **Pro 模式采用率**：解锁 Pro 的专业活跃用户占活跃用户比例。
- **Alpha 因子使用率**：因子副驾生成 → 模拟 →（用户）采纳的比例。
- **MCP 工具安装数**：第三方工具接入量，佐证生态开放度。
- **记忆召回率**：知识图谱在固定 benchmark 上的 recall/precision 不低于 native baseline（不允许更差）。

V3 退出标准：专业用户能在研究→因子→模拟→决策全链工作；MCP 生态可扩展；技术债清零让迭代回归可控；北极星指标可统计。

## 8.4 阶段衔接逻辑

### 为什么是这个顺序（why）

三阶段是**价值递增 + 风险递减**的刻意排序，不是按功能堆砌：

**V1 解决的是"入口与断链"**。当前最大的问题不是能力不够（4 条流水线、13 工具、证据纪律都已建成），而是**能力散、入口乱、闭环断**——用户不知道去哪、研究完不知道该干嘛。所以 V1 必须先做"收敛"而非"新功能"：统一入口、修好研究→关注断链、把已有的强项（证据/流水线）可视化。此时的优先级是**减负**：所有新概念必须在统一入口与三个中心之内消化，新手 10 分钟能跑通第一个闭环，为后续一切建立"会用"的前提。

**V2 解决的是"主动与质量"**。入口通了、用户在用了之后，才开始谈"持续"。委员会与管家的价值依赖"已有研究/论文/组合被用户使用"+ "可以主动访问的数据"— 这些资产正是 V1 统一后沉淀下来的。V2 用主动监控把低频研究变高频跟踪，用多 agent 对抗提升单点判断质量。

**V3 解决的是"专业与生态"**。要在"用的好 + 跟得住"之上再加"算得准 + 能扩展"。而专业量化（Alpha 副驾）和生态开放（MCP）都要站在**干净、可扩展、已通闭环**的基座上：因子模拟要复用回测/风险引擎，MCP 要复用任务路由与工具注册，记忆图谱要复用 memory+evidence 合同。这些前提由 V1/V2 建好。

### 阶段间依赖（what must precede）

**V2 必须等 V1** 交付的硬前提：
1. **统一 AI 研究中心** + 命令栏——委员会的会议输入、管家的上下文都来自统一研究资产，没有收敛就无法组织集体讨论。
2. **研究→关注断链修复**——管家要"盯"的对象清单（自选/组合）必须先存在，否则没有巡检对象。
3. **证据链 + 术语 + TTFV**——委员会与管家输出必须建立在用户"已经看得懂、信得过"的研究语言上，否则主动机制只会放大困惑。
4. **decision inbox + memory 可用**——管家/委员会产生的下一步与决策必须有落点，V1 已具备，V2 才接得上。

**V3 必须等 V1+V2** 交付的硬前提：
1. **任务路由 + 工具注册（V1）**——MCP 市场要挂到同一套工具注册与调用/权限语义，否则第三方工具无法安全接入。
2. **记忆 + 证据合同（V1/V2 成熟）**——知识图谱是"可重建读模型"，必须站在既有 memory/evidence 类型之上，不能另起炉灶。
3. **回测/风险/引擎稳定（V2 删除 legacy 后）**——Alpha 副驾的"模拟 + IC 计算"要复用的是**唯一、正确、无 tech debt**的 v2 引擎，只有 V2 清完旧回测与旧表，量化副驾才有可信的底座。
4. **E2E / 幂等 / 技术债（V3 自清）**——专业功能一旦开放（Pro、MCP、多模型），回归面大增，必须先有测试与幂等兜底（这正是为何技术债清算放在 V3 开头、而非 V1）。

### V2 为 V3 提供了什么（what V2 enables）

- 委员会与管家的**主动监控资产**（thesis、portfolio、monitor targets）成为 V3 Pro/Alpha 副驾的输入：因子研究可直接对"用户正在跟踪的 thesis 敞口"验证。
- V2 的把单 agent 辩论升级为多 agent 交锋，其**对抗议程**可被 V3 的知识图谱与因子副驾复用为"证伪某因子逻辑"的讨论骨架。
- 自动刷新 + 漂移监控证明"系统会持续长记性"，为 V3 知识图谱"跨时间关联证据"确立用户心智与数据积累。

### 一个问题一个问题地解决（how）

- **V1 的问题**："我打开它不知道该干嘛，研究了也不知道下一步" → 统一入口 + 断链修复 + 证据可见。
- **V2 的问题**："我得手动盯，且单个 agent 的结论我不太敢信" → 主动管家 + 委员会集体对抗 + 漂移自动提醒。
- **V3 的问题**："我想做专业量化 / 想扩展工具，但系统是封闭的、底子是脆的" → Alpha 副驾 + MCP 生态 + 技术债清算 + 多模型路由。

三阶段共同服务同一个北极星：**每周产生可执行投资决策的活跃研究会话**。V1 让会话产生（入口通、能完成）、V2 让会话变决策（主动推动下一步）、V3 让决策更专业且可扩展（量化验证 + 生态）。每一步都在为下一步铺地基，且每一步都以"用户可感知价值 × 复用已建成资产"为排序原则，不追架构时髦、不引入 LangGraph/ORM/图数据库进权威主路径。
