# 五项能力启动测试矩阵

## 产品目的

首次打开金融产品时，用户最需要确认的不是菜单是否齐全，而是五条关键能力链是否真的可用。本矩阵把项目引用的五个外部设计方向转换为可见、可点击、可复核的启动测试；它们不是对外部仓库的代码复用。

| 能力链 | 参考方向 | 启动查询 | 成功判据 | 是否消耗模型额度 |
|---|---|---|---|---|
| 多市场数据 | daily_stock_analysis | `600519, 00700, AAPL` | 三个市场均返回行情与 60 日收益，单个失败需显示具体代码 | 否 |
| 技术分析 | stock-analyzer | `AAPL` | K 线、指标、信号、评分均有值或给出可解释的数据源错误 | 否 |
| 投研问答 | Vibe-Trading | `请从商业模式、竞争壁垒和主要风险三个角度分析 Apple。` | 问题已预填；用户新建会话并确认发送后才调用模型 | 是，需用户确认 |
| 多视角讨论 | ai-berkshire | `Apple 是否适合长期持有？...` | 四个默认角色与主题已预填；创建后、开始前仍由用户确认 | 是，需用户确认 |
| Alpha 因子研究 | wq-alpha-research | `operating_income` | 返回内置字段的 ID、描述与数据集/类别信息 | 否 |

## 交互原则

1. 仪表盘的“五项能力启动测试”是明确的首屏入口，不再只提示单一 A 股代码。
2. 可离线或免费验证的行情、技术与字段查询可以直接执行；模型推理永远只预填问题，不在用户未确认时产生费用或写入历史。
3. 多市场失败必须保留失败代码和原因，不能用零值或假数据伪装成功。
4. Alpha 页面只做本地字段与模板检索；不含 WorldQuant 登录、模拟、提交或任何账户操作。

## 运行验证

```powershell
cd backend
.venv\Scripts\python.exe -m pytest -q

cd ..\frontend
bun run build
```

运行中的本地后端与前端需重启或热更新后，打开仪表盘执行五项启动测试。模型相关两项需要已配置可用的 OpenAI 兼容模型；其余三项不依赖模型密钥。
